Block theme for a (fictional) Indonesian architecture and interior design studio. Based on Frost by WP Engine.

== Description ==

Studio Arunika adalah tema blok WordPress untuk studio arsitektur dan desain interior. Tema ini memakai palet bernuansa tanah (pasir, batu hangat, zaitun tua, dan aksen terakota), judul serif yang anggun dengan teks isi Outfit, serta pola siap pakai berbahasa Indonesia: hero studio, perkenalan, layanan (Arsitektur, Interior, Renovasi), grid portofolio proyek, alur kerja, testimoni contoh, dan ajakan kontak.

Studio Arunika is a derivative of the Frost block theme by WP Engine. All studio names, projects, addresses and testimonials in the patterns are fictional sample content.

== Installation ==

1. Download or clone this repository and place the folder in `wp-content/themes/`.
2. In the WordPress admin, go to Appearance > Themes and activate "Studio Arunika".
3. Optional: set Settings > Reading to a static front page to use the Arunika front-page layout, and pick a style variation (Arunika Malam or Arunika Batu) under Appearance > Editor > Styles.
